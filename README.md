# banda110/site-shahdan-8

موقع ذكريات لمناسبة خاصة — مبني على محرك Memory Studio.

## 🚀 النشر على Vercel

1. افتح [Vercel](https://vercel.com) وسجّل الدخول بحسابك المربوط بـ GitHub.
2. اضغط **Add New → Project** واختار هذا الريبو من القائمة (هيبان تلقائياً لأنه خاص بك).
3. اضغط **Deploy** — لا حاجة لأي إعدادات.
4. الرابط النهائي هيبقى زي: `https://site-shahdan-8.vercel.app`

[![Deploy to Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/banda110/site-shahdan-8)

## 🔒 الحماية

- صفحة الزائر محمية بكلمة سر محددة من لوحة الإدارة.
- أي تعديلات من لوحة التعديل المدمجة تنشر عبر مالك الموقع (لوحة الأدمن).
